# Nesmaya Sports AI v0.3

تنفيذ فعلي لطبقة بيانات اللاعبين.

- إضافة لاعب فعليًا داخل حالة التطبيق.
- رقم القميص.
- اسم اللاعب.
- الفريق.
- المركز.
- أهداف وتمريرات وتسديدات كبنية بيانات جاهزة للربط لاحقًا بتحليل الفيديو.
- حقول المسافة والسرعة جاهزة للمرحلة القادمة.

المرحلة التالية: ربط البيانات بتسجيل/اختيار الفيديو ثم طبقة اكتشاف وتتبع اللاعبين والكرة.
